# LG INR21700-M50T 真实参数与当前有效参数对比

日期：2026-08-28  
比较对象：当前工程的 PyBaMM 26.7.1 `SPMe + OKane2022` 有效参数  
范围：不讨论或比较 SEI、析锂、LAM 倍率

## 1. 结论摘要

当前参数并不是与 LG M50T 完全无关的通用参数：PyBaMM 的 `OKane2022` 以 Chen 等人表征的 **LG M50** 为电化学基础，再加入 O'Kane 等人的老化模型参数。LG M50T 是 M50 的后续型号，两者相近但并不相同。

与直接针对 M50T 的拆解、SEM/EDS/GDOES、半电池和 GITT 表征数据相比，当前模型最重要的差异是：

1. **真实 M50T 使用石墨/SiOₓ 复合负极；当前模型只有一个石墨负极相。** M50T 的硅质量分数综合测量结果约为 `2.43 wt%`，对应约 `18%` 的整电芯容量贡献；当前模型的 SiOₓ 相及其 OCP、扩散、颗粒尺寸和力学行为均为缺失。
2. **当前有效电极面积小于 M50T 拆解实测面积。** 当前用同一个 `982.13 cm²` 面积表示正负极，而 M50T 实测负极/正极涂层面积分别约为 `1098.5/1050.4 cm²`。
3. **隔膜厚度差异明显。** 当前为 `12.0 µm`，M50T 实测约为 `16.7 µm`；当前值实际对应早期 LG M50 表征值。
4. **正极涂层电子电导率差异很大。** 当前为 `0.18 S·m⁻¹`，M50T 实测为 `5.88 S·m⁻¹`，当前值约为实测值的 `3.1%`。
5. **电极孔隙率、集流体厚度、颗粒半径和扩散系数也存在差异。** 其中扩散系数因定义和测量方法不同，不能直接把 GITT 均值覆盖到 PyBaMM 函数中。
6. **当前分层热参数折算的卷芯质量比热约为 `653 J·kg⁻¹·K⁻¹`，低于 M50T 在约 300 K 下的实测 `908–912 J·kg⁻¹·K⁻¹`，约低 `28%`。**

外形、质量、W10 环境温度、标称容量和电压边界已经与 Stanford W10 数据集使用的 M50T 电芯一致。

## 2. 可信来源与采用规则

本报告只采用以下来源中的厂家规格或直接实验测量值：

1. **LG Chem 产品规格书**：`INR21700 M50T 18.2 Wh`，2018-07-16，Rev.0。用于确认厂家额定电压、充放电边界和标准测试条件。公开镜像：[LG Chem INR21700 M50T Product Specification](https://e2e.ti.com/cfs-file/__key/communityserver-discussions-components-files/196/INR21700M50T.pdf)。
2. **Stanford M50T 实车工况老化数据集论文**：对实际 `INR21700-M50T` 电芯开展 W10 等测试。用于确认本项目对应样品的型号、化学体系、尺寸、质量、4.85 Ah 容量口径、温度和截止条件：[Pozzato et al., Data in Brief 2022](https://pmc.ncbi.nlm.nih.gov/articles/PMC8892076/)。本地原文位于 `E:/battery/data/LG M50T/Lithium-ion battery aging dataset based on electric vehicle real-driving profiles.pdf`。
3. **M50/M50T/M50LT 直接拆解与电化学表征**：通过尺寸测量、SEM、EDS、GDOES、半电池和 GITT 对 M50T 进行专门表征。用于本报告的内部几何、孔隙率、涂层电导率、颗粒尺寸、扩散系数和硅含量：[Stapf et al., Journal of The Electrochemical Society 172 (2025) 060513](https://doi.org/10.1149/1945-7111/add112)。
4. **M50T 热物性实验**：用于卷芯质量比热和穿层热导率参考：[Steinhardt et al., Journal of Energy Storage 42 (2021) 103065](https://doi.org/10.1016/j.est.2021.103065)。
5. **当前模型来源**：工程的参数装配见 [`src/pybamm_w10/model.py`](../../src/pybamm_w10/model.py)，容量面积倍率见 [`inputs/spme_transferred_parameters.json`](../../inputs/spme_transferred_parameters.json)，运行有效值见 [`effective_parameters.json`](../../outputs/pybamm_spme/w10-350-solver-resilience-v1/effective_parameters.json)。

未采用电商页面、论坛、电芯转售商二次整理表，也未把 LG M50 或一般 21700 电芯的值当作 M50T 实测值。由于商业电芯存在批次与生产公差，拆解数据应理解为可信的实测样品值，而不是每一颗 M50T 都完全相同的绝对常数。

### 面积计算说明

当前模型：

```text
Electrode height = 0.065 m
Effective electrode width = 1.58 × 0.95630859375
                          = 1.510967578125 m
Effective area = 0.065 × 1.510967578125
               = 0.0982128926 m²
               = 982.13 cm²
```

M50T 拆解测量：

```text
Negative coating area = 1098.5 cm²
Positive coating area = 1050.4 cm²
```

因此，当前的容量已经匹配，并不表示内部几何已经匹配。若直接用实测面积替换当前等效面积，必须同时重新辨识活性材料体积分数、可用化学计量窗口或最大浓度，否则 cycle-0 容量会被重复放大。

厂家规格书中还常以 `5.0 Ah / 18.2 Wh` 表述典型容量，而 Stanford W10 数据集及其论文采用 `4.85 Ah` 作为额定容量和 C-rate 基准。本项目针对 W10 样品，继续采用 `4.85 Ah` 是正确口径，不应因厂家“典型容量”表述改为 `5.0 Ah`。

## 5. 有资料但不能直接一一替换的参数

以下项目不能仅凭公开 M50T 资料进行可靠的单值覆盖：

| 当前参数类别 | 原因 |
|---|---|
| 最大固相浓度、初始浓度和化学计量端点 | M50T 文献主要给出实测容量、半电池曲线和电极平衡，不等同于 PyBaMM 中完整的 `c_max` 与初始化学计量参数。需联合 OCP 和容量窗口辨识。 |
| 活性材料体积分数 | M50T 论文给出孔隙率、涂层密度和硅含量，但粘结剂/导电剂及两种负极活性相的体积分配需要一致的复合电极建模口径。不能简单用 `1 - porosity` 替代。 |
| OCP 函数 | 当前函数来自 LG M50/Chen2020。M50T 尤其需要石墨和 SiOₓ 两条独立 OCP/滞回关系，不能用一个常数修正。 |
| 交换电流密度 | 需要与实际反应面积、粒径、活性相体积分数和温度函数联合辨识。 |
| 电解液扩散率、电导率和迁移数 | 没有找到与当前 W10 批次完全对应、可直接映射到 PyBaMM 的 M50T 原厂标量；继续标为“未证实”，不应宣称为真实 M50T 值。 |
| 总换热系数 `10 W·m⁻²·K⁻¹` | 这是实验装夹、气流与边界条件共同决定的换热边界，不是 M50T 固有材料参数；不能与电芯拆解参数直接比较。 |
| 穿层热导率 | M50T 实测约 `1.25–1.36 W·m⁻¹·K⁻¹`，随 OCV/温度变化；当前运行使用 lumped thermal，分层热导率并不以同一方向和同一形式进入模型，不能直接把该值覆盖到某一层。 |

## 6. 差异的影响优先级

| 优先级 | 差异 | 对当前结果的潜在影响 |
|---|---|---|
| P0 | 缺失 SiOₓ 负极相 | 影响低 SOC 电压、有效容量分配、扩散极化、应力、热和长期容量保持；属于模型结构差异，不是改一个标量能解决。 |
| P0 | 用单一等效面积替代两极真实面积 | 当前容量匹配掩盖了几何、材料容量和化学计量窗口之间的补偿关系。 |
| P1 | 正极电子电导率 `0.18` 对 `5.88 S·m⁻¹` | 会改变高倍率下的固相电势降；对 W10 3C 充电尤其值得重新验证。 |
| P1 | 隔膜 `12.0` 对 `16.7 µm`，以及孔隙率差异 | 影响电解液浓差极化和欧姆损失。 |
| P1 | 负极/正极扩散参数差异 | 影响高倍率电压与颗粒浓度梯度；需曲线级重新参数化。 |
| P1 | 热容量偏低约 28% | 可能高估温升速度和温度波动，从而进一步影响温度敏感动力学。 |
| P2 | 集流体、涂层厚度和颗粒半径的小幅差异 | 单项通常小于上述结构差异，但在联合参数化中仍应更新。 |

## 7. 最终判断

当前有效参数可以表述为：

> **以 LG M50/OKane2022 为基础、用 W10 cycle-0 容量缩放过有效面积、并采用 M50T 外形和实验边界的单相 SPMe 参数集。**

它还不能严谨地表述为“LG M50T 真实参数集”。在不讨论 SEI、析锂和 LAM 倍率的前提下，至少仍有四类核心差异：

- M50T 的石墨/SiOₓ 复合负极尚未建模；
- 正负极真实面积与当前等效面积不一致；
- 隔膜、孔隙率和正极电子电导率与 M50T 实测值不一致；
- 热容量与 M50T 实测值存在明显差异。

其中，复合负极和面积/容量联合辨识是前置问题。若不先处理这两项，仅把厚度、孔隙率或电导率逐项替换为实测值，原来已经匹配的 cycle-0 容量和电压曲线很可能失配。
